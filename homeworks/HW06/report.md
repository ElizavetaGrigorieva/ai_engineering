## 1. Dataset

- Какой датасет выбран: `S06-hw-dataset-01.csv`
- Размер: (2000 строк, 15 столбцов)
- Целевая переменная: `target` (бинарная переменная с двумя классами в соотношении примерно 75% к 25%)
- Признаки: числовые признаки (14 признаков без id и target)

## 2. Protocol

- Разбиение: train/test в пропорции 80%/20% с `random_state=42` и стратификацией (`stratify=y`) для сохранения пропорций классов
- Подбор: кросс-валидация на train с 5 фолдами (cv=5), оптимизация по метрике ROC-AUC
- Метрики: accuracy, F1, ROC-AUC (метрики выбраны для оценки качества бинарной классификации, ROC-AUC особенно важен для оценки способности модели различать классы)

## 3. Models

Сравнивались следующие модели с подбором гиперпараметров:

Минимум:

- DummyClassifier (baseline с предсказанием самого частого класса)
- LogisticRegression (baseline из S05 с масштабированием признаков)
- DecisionTreeClassifier (контроль сложности: `max_depth` и `min_samples_leaf`)
- RandomForestClassifier (ансамбль деревьев с настройкой `n_estimators`, `max_depth`, `min_samples_leaf`, `max_features`)
- GradientBoostingClassifier (градиентный бустинг с настройкой `n_estimators`, `learning_rate`, `max_depth`)

Опционально:

- StackingClassifier (содержащий RandomForest, GradientBoosting и LogisticRegression как базовые модели, с логистической регрессией как финальным эстиматором)

## 4. Results

 Model  Accuracy  F1  ROC_AUC 
 Dummy  0.7450  0.0000  - 
 Logistic Regression  0.8525  0.6383  0.9142 
 Decision Tree  0.8875  0.7353  0.9405 
 Random Forest  0.9025  0.7692  0.9480 
 Gradient Boosting  0.9050  0.7736  0.9495 
 Stacking  0.9075  0.7778  0.9502 

Лучшая модель по ROC-AUC: StackingClassifier (ROC-AUC: 0.9502). Эта модель объединяет силу нескольких алгоритмов и показывает наилучшее качество в задаче классификации.

## 5. Analysis

- Устойчивость: в рамках домашнего задания была реализована фиксация random_state для воспроизводимости результатов, что позволяет получать одинаковые результаты при повторных запусках.
- Ошибки: confusion matrix для лучшей модели (Stacking) показывает хорошую способность модели различать положительный и отрицательный классы, с минимальным количеством ложно положительных и ложно отрицательных результатов.
- Интерпретация: permutation importance позволила определить наиболее значимые признаки для предсказания целевой переменной. Top-15 признаков были определены и визуализированы, что помогает понять, какие факторы наиболее влияют на принятие решения моделью.

## 6. Conclusion

1. Ансамблевые методы (Random Forest, Gradient Boosting, Stacking) значительно превосходят одиночные деревья и логистическую регрессию по качеству предсказаний.
2. Stacking показал наилучший результат, эффективно объединяя различные модели для повышения обобщающей способности.
3. Контроль сложности деревьев (через max_depth и min_samples_leaf) помогает предотвратить переобучение.
4. Использование ROC-AUC как основной метрики оказалось эффективным для оценки качества бинарной классификации.
5. Перестановочная важность (permutation importance) позволяет интерпретировать модели и выявлять наиболее значимые признаки.
