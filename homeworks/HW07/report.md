## 6. Conclusion

4-8 коротких тезисов: чему научились про кластеризацию, метрики и корректный протокол unsupervised-эксперимента.

1. KMeans работает хорошо при сферических кластерах и одинаковой плотности, но плохо справляется с нелинейными структурами.
2. DBSCAN эффективен для данных с произвольной формой кластеров и может определять шумовые точки.
3. AgglomerativeClustering позволяет исследовать иерархическую структуру данных и чувствителен к выбору функции связи.
4. Внутренние метрики (silhouette, Davies-Bouldin, Calinski-Harabasz) полезны для оценки качества кластеризации без истинных меток.
5. Масштабирование признаков критически важно для distance-based методов кластеризации.
6. PCA визуализация помогает визуально оценить качество кластеризации и структуру данных.
7. Проверка устойчивости результатов важна для доверия к полученным кластерам.
8. Подбор гиперпараметров должен основываться на нескольких метриках, а не только на одной.
